# آیکن پلتفرم‌های لینک‌سازی

هر فایل، فاوآیکن دامنه‌ی یک `LinkPlatform` است. نام فایل **دامنه با خط تیره**
است و همین تنها چیزی است که فایل را به پلتفرم وصل می‌کند:

```
aparat.com  →  aparat-com.png
shop.snapp.ir  →  shop-snapp-ir.png
```

⚠️ **سرور هیچ‌وقت برای آیکن به اینترنت وصل نمی‌شود** — نه موقع ساخت پلتفرم، نه
موقع نمایش فهرست، نه در سید. گرفتن آیکن کارِ لپ‌تاپ توسعه است؛ فایل در گیت
کامیت می‌شود و با rsync دیپلوی می‌رود. دلیلش سه چیز است: دکمه‌ی ذخیره ثانیه‌ها
معطل می‌ماند، سرور به سرویس بیرونی وابسته می‌شود، و از شبکه‌ی ایران نیمی از
دامنه‌ها اصلاً جواب نمی‌دهند.

⚠️ **مسیر آیکن از روی دامنه حدس زده نمی‌شود.** پسوند همیشه `png` نیست و مسیری
که به فایل موجود اشاره نکند یعنی یک ۴۰۴ روی هر بار رندر فهرست. ستون `iconPath`
را فقط سید و اسکریپت می‌نویسند (با `existsSync`)؛ خالی بودنش یعنی آیکن **نوع**
نشان داده می‌شود.

دامنه‌ای که آیکنش نیست، انتهای `scripts/seed-link-types.ts` فهرست می‌شود.
