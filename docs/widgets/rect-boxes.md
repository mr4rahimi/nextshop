## ۱ — بیرون‌زدگی تصویر بدون بریده‌شدن

تصویر با `position: absolute` پایین‌تر از کف باکس کشیده می‌شود:

```tsx
<div style={{ bottom: -ov, height: `calc(100% + ${ov}px)` }}>
```

مشکل اینجاست که سوایپر `overflow: hidden` دارد و تصویرِ بیرون‌زده را می‌بُرد.
راه‌حل‌های ممکن و انتخاب:

- ❌ `overflow: visible` روی سوایپر (کاری که بعضی ویجت‌های قدیمی می‌کنند) —
  اسلایدهای کناری هم از دو طرف بیرون می‌زنند و افکت «نمایش بخشی از باکس سوم»
  خراب می‌شود.
- ✅ **`padding-bottom` روی خود سوایپر** به اندازه‌ی همان بیرون‌زدگی (+۴ پیکسل).
  ناحیه‌ی padding داخل کادرِ clip قرار می‌گیرد، پس تصویر کامل دیده می‌شود ولی
  اسلایدهای کناری همچنان بریده می‌شوند.

نتیجه اینکه فاصله‌ی زیر ویجت هم خودکار به همان اندازه بیشتر می‌شود و تصویر روی
ویجت بعدی نمی‌افتد.

اندازه‌گیری واقعی با `imageOverflow: 20` → تصویر دقیقاً ۲۰ پیکسل پایین‌تر از کف
باکس و `padding-bottom` سوایپر ۲۴ پیکسل.

تصویر با `object-contain object-bottom` رندر می‌شود تا محصول روی کف باکس بنشیند
و تصاویر بدون پس‌زمینه درست دربیایند.

## ۲ — رنگ‌بندی هر باکس

هر باکس پس‌زمینه‌ی مستقل دارد: رنگ ساده یا گرادینت با شش جهت. در نمونه‌ای که
مبنا بود هر دسته رنگ خودش را داشت، پس تنظیم مشترک جواب نمی‌داد.

رنگ متن **دستی نیست**: از روشناییِ پس‌زمینه‌ی همان باکس حساب می‌شود. یعنی باکس
زرد روشن خودکار متن تیره می‌گیرد و باکس سرمه‌ای متن روشن — بدون اینکه ادمین
درگیر انتخاب رنگ خوانا شود. در ادمین هم کنار انتخابگر رنگ نوشته می‌شود که رنگ
متن خودکار «تیره» یا «روشن» خواهد بود.

برچسب کوچک هم پس‌زمینه‌اش از همان رنگ متن با شفافیت کم ساخته می‌شود
(`${color}22`) تا در هر رنگ‌بندی هماهنگ بماند.

## ۳ — ماژول مشترک کنتراست

محاسبه‌ی رنگ متن قبلاً داخل `CircleGallerySection` بود. حالا به
`lib/contrastColor.ts` منتقل شده و هر دو ویجت از آن استفاده می‌کنند:

```ts
export function luminance(hex: string): number         // روشنایی نسبی sRGB طبق WCAG
export function contrastTextColor(...bg: string[]): string  // برای گرادینت میانگین می‌گیرد
```

`luminance()` روی ورودی نامعتبر مقدار ۱ برمی‌گرداند (یعنی متن تیره)، پس رنگ خراب
هیچ‌وقت باعث متن نامرئی نمی‌شود.

## ۴ — پنل ادمین

- **تنظیمات کلی**: عنوان و زیرعنوان بخش، اسلایدر بیرون‌زدگی تصویر (۰ تا ۴۸px)،
  سوییچ فلش‌ها و سوییچ اسلاید خودکار با اسلایدر زمان‌بندی.
- **پیش‌نمایش زنده**: باکس‌ها با همان رنگ، همان بیرون‌زدگی و همان رنگ متن خودکار
  رندر می‌شوند — دقیقاً همان چیزی که در سایت دیده می‌شود.
- **مدیریت باکس‌ها**: افزودن، حذف، جابه‌جایی با ↑ ↓، آپلود تصویر، و برای هر باکس
  سه فیلد متنی (عنوان، توضیح، برچسب) + لینک + انتخابگر پس‌زمینه.

## تست انجام‌شده

`tsc --noEmit` بدون خطا. تست با مرورگر واقعی:

| سناریو | نتیجه |
|---|---|
| موبایل | دو باکس ۱۰۰٪ و باکس سوم ۲۰٪ دیده می‌شود ✓ |
| بیرون‌زدگی تصویر با مقدار ۲۰ | دقیقاً ۲۰px زیر کف باکس، بدون بریده‌شدن ✓ |
| `padding-bottom` سوایپر | ۲۴px — خودکار متناسب با بیرون‌زدگی ✓ |
| دسکتاپ ۱۴۴۰px | ۴ باکس در یک ردیف ✓ |
| رنگ متن خودکار | باکس زرد → متن تیره، باکس سرمه‌ای/بنفش/فیروزه‌ای → متن روشن ✓ |
| `imageOverflow: 999` | هنگام رندر به ۴۸ کلمپ شد ✓ |
| رنگ نامعتبر (`"notacolor"`) | به رنگ پیش‌فرض برگشت ✓ |
| صفحه‌ی ویرایش در مرورگر | همه‌ی بخش‌ها و پیش‌نمایش زنده درست ✓ |

ویجت تستی از دیتابیس حذف شد.
