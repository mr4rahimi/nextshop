## ۶. On-Page و Schema

**درست کار می‌کند:**
- `robots.txt` تمیز و درست، با اعلام sitemap
- `sitemap.xml` با ۳۰۵۱ آدرس معتبر
- HTTPS با HSTS، `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`
- ریدایرکت HTTP → HTTPS
- `lang="fa"` و `dir="rtl"` درست
- JSON-LD: `Organization`, `WebSite`, `Store` در صفحه‌ی اصلی؛ `Product` + `BreadcrumbList` در محصول؛ `Article` + `BreadcrumbList` در مقالات
- عنوان و توضیحات متا در صفحات محصول و دسته باکیفیت و اختصاصی
- alt تصاویر کامل است
- صفحه‌ی ۴۰۴ کد ۴۰۴ واقعی برمی‌گرداند (نه soft-404)

**مشکل دارد:**
- **صفحه‌ی اصلی H1 ندارد**
- عنوان صفحه‌ی اصلی فقط «مهام پرینت» است — بدون کلمه‌ی کلیدی
- توضیحات متای صفحه‌ی اصلی ~۴۰۰ کاراکتر است (در نتایج بریده می‌شود)
- **`https://www.mahamprint.com/` کد ۲۰۰ می‌دهد و ریدایرکت نمی‌شود** (فقط canonical آن را نجات می‌دهد)
- کنونیکال صفحه‌ی اصلی `https://mahamprint.com` بدون `/` است ولی سایت‌مپ هم همین را دارد — سازگار است
- `Product` schema فاقد `sku`, `gtin`, `aggregateRating`
- `trackStock` برای ۲۷۵۴ محصول فعال است ولی همه `InStock` اعلام می‌شوند
