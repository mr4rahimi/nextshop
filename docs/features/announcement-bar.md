# نوار اعلان بالای سایت

یک نوار باریک بالاتر از **هر چیز دیگری** (حتی لوگو و ردیف اول هدر) روی همه‌ی
صفحات فروشگاه. مناسب اعلان‌های موقت — مثل «قیمت‌ها نوسان دارد، قبل از سفارش
تماس بگیرید». کاربر می‌تواند با ضربدر آن را ببندد و دیگر نبیند.

| موضوع | فایل |
|---|---|
| نوع، پیش‌فرض‌ها، `normalizeAnnouncementBar()`، `announcementKey()` | `lib/announcementBar.ts` |
| کامپوننت نوار | `components/layout/AnnouncementBar.tsx` |
| اتصال به سایت (و ظرف چسبان) | `components/layout/Header.tsx` |
| تنظیمات ادمین | `app/admin/site-settings/page.tsx` — تب «نوار اعلان» |
| ذخیره‌سازی | `StoreSettings.announcementBar` (Json?) |

---

## تنظیمات ادمین

**ادمین ← تنظیمات سایت ← تب «نوار اعلان»**

اینجا انتخاب شد چون نوار روی **کل سایت** اعمال می‌شود و هم‌خانواده‌ی تب «هدر
سایت» است؛ نه یک ویجت صفحه اصلی (ویجت‌ها فقط در صفحه‌ی اصلی‌اند و ترتیب‌پذیرند)
و نه یک برگه‌ی ثابت.

| کلید | معنی |
|---|---|
| `enabled` | نمایش نوار |
| `text` | متن پیام (حداکثر ۳۰۰ کاراکتر، بدون HTML) |
| `linkUrl` | لینک اختیاری؛ خالی یعنی نوار کلیک‌پذیر نیست |
| `bgColor` / `textColor` | رنگ پس‌زمینه و متن (hex) |
| `dismissible` | نمایش دکمه‌ی ضربدر |
| `sticky` | چسبان بالای صفحه یا فقط ابتدای صفحه |

پنل یک **پیش‌نمایش زنده** هم دارد و پنج رنگ آماده (آبی، قرمز هشدار، کهربایی،
سبز، مشکی).

نوار فقط وقتی رندر می‌شود که `enabled` روشن **و** `text` غیرخالی باشد
(`isAnnouncementVisible()`).

## بستن توسط کاربر — و اینکه چطور دوباره برمی‌گردد

انتخاب کاربر در `localStorage` با کلید `announcement-dismissed` ذخیره می‌شود.
مقدارِ ذخیره‌شده **هش متن و لینک** است، نه یک `true` ساده:

```ts
announcementKey(cfg) // هش djb2 از `${text}|${linkUrl}` در مبنای ۳۶
```

نتیجه: وقتی ادمین متن اعلان را عوض می‌کند، کلید هم عوض می‌شود و پیام جدید
دوباره به همه‌ی کاربران — از جمله آن‌هایی که پیام قبلی را بسته بودند — نشان داده
می‌شود. ادمین لازم نیست چیزی را دستی ریست کند و فیلد «نسخه» هم در دیتابیس
ذخیره نمی‌شود.

### چرا مخفی‌سازی با اسکریپت inline است، نه با state

اگر برای مخفی‌کردن نوار منتظر hydration می‌ماندیم، کاربری که نوار را بسته بود در
هر بار لود یک فریم آن را می‌دید و کل صفحه به‌اندازه‌ی ارتفاع نوار می‌پرید — همان
مشکل flash که در dark mode داشتیم.

به‌جای آن، یک اسکریپت inline داخل خود نوار قبل از اولین رنگ‌آمیزی اجرا می‌شود و
فقط یک **کلاس روی `<html>`** می‌گذارد:

```js
if (localStorage.getItem("announcement-dismissed") === KEY)
  document.documentElement.classList.add("ann-off");
```

```css
html.ann-off .ann-bar{display:none}
```

> اسکریپت عمداً به DOMِ تحت مدیریت React دست نمی‌زند (نه `style` عنصر را عوض
> می‌کند نه `hidden` می‌گذارد) — فقط کلاس روی `<html>`. همان الگوی
> `ThemeProvider`. هر راه دیگری hydration را با mismatch روبه‌رو می‌کند.

کلیک روی ضربدر: ارتفاع نوار با انیمیشن به صفر می‌رسد (۲۸۰ms)، سپس همان کلاس
روی `<html>` می‌نشیند و مقدار در `localStorage` ذخیره می‌شود.

## حالت چسبان و رابطه‌اش با هدر

همه‌ی هدرها خودشان `position:sticky; top:0` دارند. اگر نوار را جداگانه
sticky می‌کردیم، هدر زیر آن می‌رفت و ردیف اولش پنهان می‌شد.

راه‌حل: در حالت `sticky`، نوار و هدر داخل **یک ظرف sticky مشترک** می‌نشینند:

```tsx
<div className="sticky top-0 z-50">
  <AnnouncementBar … />
  <HeaderSwitcher … />
</div>
```

ظرف به‌عنوان یک واحد می‌چسبد؛ هدرِ داخلش در جعبه‌ی والد و دقیقاً زیر نوار
می‌ماند. **هیچ‌کدام از سه هدر لازم نشد تغییر کنند** و اگر نوار خاموش باشد ظرف
اصلاً رندر نمی‌شود و ساختار قبلی دست‌نخورده باقی می‌ماند.

نکات z-index:
- ظرف `z-50` است (هدرها داخلش `z-40` دارند).
- اورلی‌های سایت (`z-[80]`, `z-[95]`, `z-[140]`, `z-[150]`, `z-[200]`) و کشوی
  منوی موبایل (`zIndex: 9000`) بالاتر از ظرف‌اند، پس چیزی زیر نوار نمی‌افتد.

در حالت غیرچسبان، نوار فقط قبل از هدر رندر می‌شود و با اسکرول بالا می‌رود.

## امنیت ورودی

`normalizeAnnouncementBar()` هم در `PUT /api/admin/site-settings` و هم موقع
خواندن در `Header.tsx` صدا زده می‌شود:

- `text` — trim و برش به ۳۰۰ کاراکتر، به‌صورت متن ساده رندر می‌شود (بدون
  `dangerouslySetInnerHTML`)
- `linkUrl` — فقط نشانی داخلی (شروع با `/`) یا `http(s)://`؛ `javascript:` و
  امثالش به رشته‌ی خالی تبدیل می‌شوند
- رنگ‌ها — فقط `#rrggbb`
- بولین‌ها — هر چیزی غیر از boolean به پیش‌فرض برمی‌گردد

## تست انجام‌شده

`tsc --noEmit` بدون خطا. روی سرور توسعه:

| مورد | نتیجه |
|---|---|
| رندر نوار قبل از `<header>` در HTML سرور | ✓ |
| نمایش در `/`, `/products`, `/brands` (هدر شیشه‌ای فعال) | ✓ |
| حالت چسبان → ظرف `sticky top-0 z-50` رندر می‌شود | ✓ |
| حالت غیرچسبان → ظرف رندر نمی‌شود | ✓ |
| اسکریپت inline با کلید هش‌شده در HTML | ✓ |
| متن خالی یا `enabled=false` → هیچ چیز رندر نمی‌شود | ✓ |
