# صفحه‌ی ورود پنل مدیریت

مسیر: `/admin/login`

- صفحه‌ی سروری: [`app/admin/login/page.tsx`](../../app/admin/login/page.tsx)
- فرم: [`components/admin/AdminLoginForm.tsx`](../../components/admin/AdminLoginForm.tsx)
- گیت مسیر: [`proxy.ts`](../../proxy.ts)
- کنارگذاشتن اسکلت پنل: [`app/admin/layout.tsx`](../../app/admin/layout.tsx)

---

## چرا این صفحه از اسکلت پنل جداست

`app/admin/layout.tsx` سایدبار، هدر و پاپ‌آپ‌های کارتابل را روی **همه‌ی** مسیرهای
`/admin/*` می‌کشد. چون فرم ورود هم زیر همین مسیر است، تا نسخه‌ی ۲.۳۶.۰ هر
بازدیدکننده‌ی ناشناسی که `/admin` را می‌زد، پشت فرم ورود کل فهرست بخش‌های
مدیریتی را می‌دید — نه یک رخنه‌ی دسترسی، ولی افشای بی‌دلیل ساختار پنل و ظاهری
نامرتب.

راه‌حل: خودِ layout مسیر ورود را کنار می‌گذارد.

```tsx
const pathname = usePathname();
if (pathname === "/admin/login") {
  return <>{children}</>;
}
```

> ⚠️ اگر روزی مسیر ورود عوض شد، این شرط هم باید عوض شود. مسیر در دو جای دیگر هم
> نوشته شده: ریدایرکت و استثنای `proxy.ts`.

## لایه‌های محافظت

| لایه | فایل | کار |
|------|------|-----|
| گیت مسیر | `proxy.ts` | هر `/admin/*` بدون توکنِ `ADMIN` به `/admin/login` می‌رود؛ خود `/admin/login` استثناست |
| گیت API | `proxy.ts` | هر `/api/admin/*` بدون توکن `401` می‌گیرد؛ فقط `/api/admin/auth/login` باز است |
| اسکلت | `app/admin/layout.tsx` | روی مسیر ورود هیچ عنصری از پنل رندر نمی‌شود |

ورود موفق علاوه بر ست‌کردن کوکی، یک `ActivityLog` و — در صورت فعال بودن کارتابل —
یک نشستِ حضور باز می‌کند. جزئیات در [کارتابل](staff-worklist.md).

---

## ظاهر

صفحه به‌عمد **فقط یک حالت** دارد (تیره) و به `ThemeProvider` وصل نیست؛ پیش از
ورود هنوز هیچ ترجیحی از کاربر نمی‌دانیم و سوسوی تغییر تم روی صفحه‌ی ورود بدتر از
نداشتن انتخاب است.

- پس‌زمینه: سه لکه‌ی نور با `blur` و یک شبکه‌ی محوشونده با `mask-image`
- کارت: شیشه‌ای (`backdrop-blur`) روی `bg-white/[0.04]`
- در نمایشگر بزرگ (`lg`) یک ستون معرفی کنار فرم می‌آید؛ در موبایل فقط فرم می‌ماند
- انیمیشن‌ها در `prefers-reduced-motion: reduce` کاملاً خاموش می‌شوند

نام و لوگو از `StoreSettings` (`storeName`، `storeLogo`) خوانده می‌شود. نبودشان
خطا نیست — نام به «فروشگاه» و لوگو به آیکن قفل برمی‌گردد.

## نکته‌های کوچک ولی مهم

- `autoComplete="username"` و `current-password` تا مرورگر رمز ذخیره‌شده را پیشنهاد بدهد
- ورودی‌ها `dir="ltr"` هستند چون شماره و رمز لاتین‌اند، ولی برچسب‌ها راست‌چین می‌مانند
- آیکن‌ها `right-0` و دکمه‌ی نمایش رمز `left-0` است؛ در RTL یعنی ابتدای فیلد و انتهای آن
- ویجت گفتگوی سایت (`AiChat` در `app/layout.tsx`) روی همه‌ی صفحات از جمله همین
  صفحه می‌آید. اگر روزی خواستید از پنل حذف شود، جای درستش `app/layout.tsx` است نه اینجا.
